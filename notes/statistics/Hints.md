# Inequalities
- For both Chebyshev and Markov, the Variance or Expectation is the thing that's greater than some probability (just to make it easier to remember)
- All inequalities in all these formulas are weak.


# Problems
- Resort to indicators + linearity for any problems asking "expected number of"
- **Symmetry** - you can use this to compute marginal probabilities. What is the chance the 2nd card you drew is an ace? just 4/52 - no need to consider conditionals.
- **Use the Complement** - birthday problem.
- **Self-referential expectations** - e.g. number of times it takes to get a heads when flipping a coin.
- **Extremes of Uniforms** - $E[\max{X_1, \cdots, X_n}]$ when they are all uniform is $n/(n+1)$. Just imagine splitting the interval into $n+1$ equal gaps using $n$ points.
- **Simulate when stuck**
