# What is a harness? 
- Everything that is not the model itself - harness is the software layer that allows the model to do work - model = agent + harness.
- Includes things like
    - system prompt
    - instructions
    - skill files
    - list of tools
    - memory
    - context management
    - orchestration
        - when to stop
        - control loop
    - execution environment
    - permissions
    - verification
    - feedback loop
    - guardrails
- Harness can cause huge performance diffs
- Harness is sometimes better than model
- Some research has gone into auto optimizing harnesses
- you can do RL inside a particular harness
